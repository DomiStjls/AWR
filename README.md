# RoboMarvel Warehouse System

## Описание проекта

RoboMarvel Warehouse System — прототип автономной роботизированной системы складской логистики на базе ROS2.

Робот самостоятельно исследует помещение, обнаруживает QR-коды, строит семантическую карту объектов склада и выполняет транспортные задачи, поступающие от серверной части.

Проект демонстрирует совместную работу мобильного робота, системы навигации, компьютерного зрения и веб-сервера управления.

---

# Основные возможности

- автономное перемещение робота;
- исследование помещения;
- обнаружение QR-кодов;
- регистрация логистических точек;
- построение семантической карты;
- получение заданий с сервера;
- перевозка грузов между точками;
- контроль вместимости складов;
- отображение состояния системы через веб-интерфейс.

# Принцип работы

## 1. Исследование помещения

После запуска робот выполняет обход помещения и строит карту.

---

## 2. Поиск QR-кодов

Во время движения робот обнаруживает QR-коды.

Каждый QR-код содержит информацию о логистической точке:

- идентификатор;
- тип объекта.

Например:

```json
{
    "id": "warehouse_A",
    "type": "warehouse"
}
```

---

## 3. Регистрация объектов

После обнаружения QR-кода сервер сохраняет:

- координаты объекта;
- тип объекта;
- идентификатор.

Поддерживаются следующие типы объектов:

- склад;
- пункт выдачи;
- станция зарядки.

---

## 4. Создание задания

Через веб-интерфейс оператор создает транспортную задачу.

Например:

```
Груз:
    Название: Box1
    Вес: 2

Откуда:
    Pickup

Куда:
    Warehouse A
```

---

## 5. Выполнение задания

Сервер отправляет роботу следующее свободное задание.

Робот:

1. едет в точку получения груза;
2. затем перемещается в точку назначения;
3. сообщает серверу об успешном завершении задания.

---

## 6. Обновление состояния

После выполнения задания сервер автоматически обновляет:

- расположение груза;
- содержимое складов;
- свободную вместимость;
- статус задания.

# REST API

## Регистрация QR-кода

POST

```
/register_qr
```

Пример запроса

```json
{
    "id": "warehouse_A",
    "type": "warehouse",
    "x": 1.42,
    "y": 0.84,
    "capacity": 20
}
```

---

## Создание задания

POST

```
/create_task
```

Пример

```json
{
    "item": {
        "name": "Box1",
        "weight": 2
    },
    "from": "pickup",
    "to": "warehouse_A"
}
```

---

## Получение следующего задания

GET

```
/get_task
```

---

## Завершение задания

POST

```
/task_done
```

---

## Статус робота

POST

```
/robot_status
```

GET

```
/robot_status
```

---

## Получение информации о складах

GET

```
/warehouses
```

---

## Получение списка заданий

GET

```
/tasks
```

---

# Структуры данных

## Груз

```json
{
    "id": 1,
    "name": "Box1",
    "weight": 2,
    "location": "warehouse_A"
}
```

---

## Склад

```json
{
    "capacity": 20,
    "free_place": 16,
    "items": [
        1,
        2,
        5
    ]
}
```

```json
    "from": "pickup",
    "to": "warehouse_A"
```
